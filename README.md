Port Solace is an original top-down open-world crime game that runs in the browser. Its city is a living grid of six districts — the Harbor, Old Town, Downtown, The Flats, Garden Row and Airstrip Flats — with lane-following traffic that queues and honks, crowds strolling the pavements, and a five-star wanted system whose police pursue, ram and box you in. You play Rook, a dock courier turned wheelman: steal and drive any car on the street, and work five story missions for Mara Voss, the fixer who runs the Harbor cafe — a first delivery, a stolen sports car for the chop shop, a checkpoint run against the clock, an escort under police pressure, and a finale that lights up every badge in the city. Busted or wasted costs a fine and a trip to the station or the hospital, never the run, and a localStorage save keeps your cash and finished jobs between visits. It is vanilla JavaScript on a 2D canvas — no engine, no build step, no assets, no network — with sound synthesised live through WebAudio and a deterministic seeded city: the same seed always builds the same streets. Walk and drive with WASD or the arrows, F gets in and out of cars, the mouse aims and click shoots on foot, and E takes the next job at Mara's cafe.

## Run it

```sh
node serve.ts
# then open http://localhost:8901
```
